# HowTo Archive (Checklist + Notes)

A simple React + Firebase app for managing reusable step-by-step processes.

## Website

[How To Archive](howto-archive.web.app)

## What is this?

This app helps you store and reuse "how-to" workflows (called TCTs — Tasks, Categories, Topics).

Examples:
- Setting up a new computer
- Daily routines in a game
- Tax preparation steps
- File backup processes

Each TCT contains:
- A checklist (with toggle + reset)
- Notes (coming soon)
- Media (planned)

---

## Features

- Create and view TCTs
- Add checklist items
- Toggle items (strike-through when complete)
- Delete checklist items
- Reset checklist
- Data persisted using Firebase Firestore

---

## Tech Stack

- React
- Firebase (Firestore)
